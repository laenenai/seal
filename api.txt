# Public API of github.com/laenenai/seal, as a golden file.
#
# Regenerate with: go test . -run TestAPIGolden -update-api
#
# "package seal" is the facade a consumer imports; "package sealtest" is the
# conformance suite it runs against its own implementation. internal/domain is
# listed too, because the facade re-exports its types as aliases: a change to
# one of those signatures changes what a consumer sees, even though the import
# path itself is private. internal/framed and internal/compact are not listed
# — the facade forwards to them rather than aliasing them, so a change there is
# a compile error in seal.go. Growing this file is a reviewed diff; see
# CHARTER.md.
